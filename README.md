This is a text-based banking application where the user is able to create accounts for customers, choose and change their balance and currency types, make transactions between accounts, query information about accounts and delete the accounts if needed. It operates with the file functions of the C so the input data are saved on some txt files to be read on the later usage of the program.

to run the program simply put these commands in your terminal:

cd (directory of the files altogether, e.g: cd Downloads\Banking_Application_Files)

g++ BankingApplication.c -o program
